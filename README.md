# Calendar — Android-приложение «Календарь задач»

Учебный проект: приложение для управления задачами с календарём на Kotlin.

## Стек технологий
- Kotlin
- Android SDK (minSdk 26, targetSdk 37)
- Room (локальная база данных)
- MVVM-архитектура
- ConstraintLayout, RecyclerView

## Этапы разработки
- [x] Этап 1: настройка окружения, главный экран со списком задач-заглушек, изучение жизненного цикла Activity
- [x] Этап 2: RecyclerView, карточки задач, FAB, переходы между экранами
- [x] Этап 3: база данных Room
- [x] Этап 4: MVVM (ViewModel, LiveData/StateFlow)
- [ ] Этап 5: добавление и редактирование задач
- [ ] Этап 6: календарь
- [ ] Этап 7: уведомления
- [ ] Этап 8: финальная сборка и оформление

Отчёты по каждому этапу — в папке `docs`.

## Запуск проекта
1. Открыть проект в Android Studio.
2. Дождаться синхронизации Gradle.
3. Запустить на эмуляторе или устройстве (minSdk 26+).
